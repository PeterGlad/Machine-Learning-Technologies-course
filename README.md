# Machine Learning Technologies — Course Materials

Teaching materials for the **Machine Learning Technologies** course at ITMO University. The repository contains lecture materials, Jupyter notebooks, practical assignments, and datasets organized by topic.

## Course contents

| Section | Topics |
|---|---|
| [00 — Introduction](00_Introduction/) | Introduction to machine learning; Python, NumPy and Pandas |
| [01 — Data preprocessing](01_Data_Preprocessing/) | Data preprocessing and feature engineering |
| [02 — Supervised learning](02_Supervised_Learning/) | Classification metrics, decision trees, random forests |
| [03 — Regularization and ensembles](03_Regularization_and_Ensembles/) | L1/L2 regularization, overfitting, ensemble methods |
| [04 — Optimization and neural networks](04_Optimization_and_Neural_Networks/) | Optimization algorithms, MLP, backpropagation |
| [05 — Natural language processing](05_Natural_Language_Processing/) | Regular expressions, word2vec, text classification |
| [06 — Convolutional neural networks](06_Convolutional_Neural_Networks/) | CNNs and transfer learning |
| [07 — Recurrent neural networks](07_Recurrent_Neural_Networks/) | Sequences and LSTMs |
| [08 — Exam](08_Exam/) | Exam questions |

## Repository structure

Each topic has its own directory. Original lecture files, notebooks, assignments, and accompanying datasets are kept together where possible. File names and notebook contents are preserved; notebooks have **not** been adapted for local execution or modified as part of this repository preparation.

## Using the materials

- PDF and PowerPoint files contain lecture materials.
- Jupyter notebooks (`.ipynb`) contain practical examples and exercises.
- Data files are stored alongside the notebooks that use them.

Some notebooks may refer to Google Colab or Google Drive paths and may require manual path adjustments depending on the execution environment.
